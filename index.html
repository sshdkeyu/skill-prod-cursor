Production skills for Cursor

Rules and skills for production software. Install the package once. On the next edit, Cursor reads AGENTS.md and the files it names, then applies them.

You do not paste the rules into the chat. The agent executes the files.

What it is

Rules 00–05The floor: done-ness, quality, security, performance, architecture, AWS. These win if a skill disagrees.
SkillsA workflow or a stack: Solid, Go, JavaScript, data access, API design, review, refactor, incidents.
ExamplesBad code, the production cost, and the replacement.
Doorskills/production sends the agent to AGENTS.md. If that file is missing, it stops.

Domain

Writing a feature, fixing a bug, reviewing a diff, shaping an HTTP contract, touching Go or JavaScript, loading a list that joins another table, or triaging a live incident.

What you get

  • One written floor, instead of a new style every chat.
  • Install asks first. The default answer is no.
  • Each rule can apply always, intelligently, to a file glob, or only when you @-mention it.
  • Go cases stay in Go. JavaScript cases stay in JavaScript. A query per row applies in every language.

Horizontal

Bad and good in two columns. On a narrow screen they stack.

Bad

preprocessed, _ := preprocess(raw)
token, err := parseLine(preprocessed[0])

Good

preprocessed, err := preprocess(raw)
if err != nil {
    return Message{}, fmt.Errorf(
        "preprocess message: %w", err)
}

The discarded error turns a truncated payload into an empty success. Check the error, then use the value. Wrap with %w when the caller needs the cause.

Vertical

Bad, the cost, then good, stacked.

Bad

posts = postRepository.findAll()
for post in posts:
    author = post.getAuthor()  # one SELECT per post
    render(post.title, author.name)

Cost

Five posts feels fine. Fifty posts is 51 round trips. No single statement looks slow, and the endpoint's p99 moves.

Good

SELECT p.id, p.title, a.name
FROM posts AS p
JOIN authors AS a ON a.id = p.author_id;

Name the columns. Bind the ids. Do not SELECT * on this path.
