# solid

How to write application code that can ship: a failing test first, then the smallest real implementation, then a cleanup that follows rules `01` and `04`.

## When to use

Implementing a feature, fixing a bug, or reshaping a module. Incident triage, API-contract review, and cloud-cost work stay on their own skills.

## Invoke

In chat: *"Use the solid skill. Add a failing test first, then implement registration."*
